# 📮 小小郵差中文字車手

一個以「中文字辨認」為核心的網頁小遊戲。玩家扮演小郵差，駕駛小車在馬路上移動，撞上題目指定的正確中文字，把信件送到學校。

**檔案編碼：UTF-8 with BOM（UTF-8-BOM）**

## 🌐 Demo

立即試玩：<https://makinggit.github.io/webgame>

## 🎮 遊戲玩法

- 每關會出現一個任務，例如：「讓車子撞上『每天』」。
- 馬路上會出現多個中文字選項。
- 玩家需要控制小車，撞向正確的文字。
- 答對可獲得星星與金幣，並累積連續答對次數。
- 答錯會扣除生命值；生命值用完後可重新開始。

## 🕹️ 操作方式

- **◀ / ▶**：向左或向右移動小車。
- **⬆️**：加速。
- **關卡選單**：選擇不同關卡。
- **更換路面**：切換路面樣式。
- **更換車色**：在車庫更換小車顏色。
- **Motion Control**：如裝置支援，可使用動作控制。

## 🎓 教育理念

本遊戲將中文字學習融入駕駛與反應挑戰，讓兒童在遊戲情境中主動辨認文字，而非被動背誦。透過即時回饋、重複練習與正向獎勵，幫助孩子建立對常用中文字的辨識能力、專注力和學習信心。

遊戲設計特別適合幼兒及初學中文的兒童：任務目標清晰、操作簡單、畫面直觀，並以「送信到學校」的具體情境，讓文字學習變得有趣而有意義。

## 📚 學習中文字的方法

- **目標辨認**：先閱讀任務，找出需要撞上的目標字。
- **字形觀察**：比較路面上的候選字，留意部首、筆畫與字形差異。
- **重複接觸**：透過多關卡與多次出現，鞏固對常用字的記憶。
- **即時回饋**：答對獲得星星與金幣，答錯會失去生命值，幫助孩子即時修正。
- **遊戲化練習**：以移動、加速和連續答對增加參與感，降低學習壓力。
